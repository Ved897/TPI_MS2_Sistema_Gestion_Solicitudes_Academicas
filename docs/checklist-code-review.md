# Checklist de Code Review

## Proyecto: Sistema de Gestión de Solicitudes Académicas

### 1. Estructura y Organización

- [x] La estructura del proyecto es clara y comprensible.
- [x] Los archivos poseen nombres descriptivos.
- [x] Las funcionalidades están separadas por responsabilidad.
- [x] No existen archivos duplicados innecesarios.

### 2. Gestión de Solicitudes Académicas

- [x] La creación de solicitudes funciona correctamente.
- [x] La consulta de solicitudes muestra información consistente.
- [x] Los datos obligatorios son validados.
- [x] Se manejan adecuadamente los errores de ingreso.

### 3. Calidad del Código

- [x] Variables y funciones poseen nombres descriptivos.
- [x] No existe código comentado innecesario.
- [x] Se evitaron duplicaciones de lógica.
- [x] El código mantiene una estructura uniforme.

### 4. Experiencia de Usuario

- [x] Los formularios son fáciles de utilizar.
- [x] Los mensajes de error son comprensibles.
- [x] Las pantallas poseen navegación clara.
- [x] El sistema informa correctamente el resultado de cada operación.

### 5. Seguridad y Validaciones

- [x] Se validan los campos obligatorios.
- [x] Se controla el ingreso de datos inválidos.
- [x] Se manejan excepciones y errores de manera adecuada.
- [x] No existen credenciales visibles en el código.

### 6. Pruebas

- [x] Se verificó la carga de solicitudes.
- [x] Se verificó la consulta de solicitudes.
- [x] Se probaron escenarios válidos e inválidos.
- [x] Se documentaron los resultados de las pruebas.

### 7. Documentación

- [x] Existe README del proyecto.
- [x] Se registraron los prompts utilizados.
- [x] Se documentaron las decisiones técnicas.
- [x] Se recopilaron evidencias de cada etapa.
